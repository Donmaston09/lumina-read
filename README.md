# Lumina Read

Transform any link into a professional audio experience.

## Quick Start
To bypass browser CORS restrictions and use the extraction features, please run this app using a local server:

```bash
# Using npm
npx serve .

# Or using Python
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.

## Features
- **Smart Extraction**: Uses Readability.js to pull just the article content.
- **Premium UI**: Glassmorphic dark theme with smooth animations.
- **Library**: Automatically saves your links for later.
- **Customizable**: Change voices and playback speed.
